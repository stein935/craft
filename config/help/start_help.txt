Usage:
  craft start -n <server_name>     Usage details: Run '$ craft start -h'

Required:
  -n <server_name>                 Name of server to start

Description:
  Starts a Minecraft server using macOS LaunchDaemons for process management.
  Creates a named pipe for server communication and monitors the startup process.
  If -n is not provided, an interactive server selection menu will be displayed.

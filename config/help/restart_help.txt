Command: restart

Usage:
  craft restart -n <server_name>     Usage details: Run '$ craft restart -h'

Required:
  -n <server_name>                   Name of server to restart

Description:
  Safely stops a running server (if running) and then starts it again.
  Logs the restart event to the server's monitor log.
  If -n is not provided, an interactive server selection menu will be displayed.

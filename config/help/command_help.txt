Command: command

Usage:
  craft command -n <server_name> -c <command [options]>   Usage details: Run '$ craft command -h'

Required:
  -n <server_name>                Name of server to command
  -c <command [options]>          Minecraft server command

Description:
  Sends a Minecraft server command to a running server through the named pipe.
  Captures and displays the server's response from the latest.log file.
  If -n is not provided, an interactive server selection menu will be displayed.
